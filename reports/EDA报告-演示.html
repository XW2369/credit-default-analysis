三个必须记住的结论

  • 缺失为 0：不需要填充。但"没有缺失"本身说明这是已清洗过的数据，不代表真实业务场景。
  • 类别不平衡 3.52:1：不算极端，不需要重采样；但评估指标不能只看 accuracy—— 全预测"不违约"就有 77.9% 的准确率。
  • 额度五分位的违约率严格单调递减：33.38% → 25.90% → 20.58% → 16.93% → 13.80%。 方向单调比 IV 高更值钱——它意味着业务可解释，且线性模型能吃下它。
坑：首行是空行、真正的列名在第 2 行 → 必须 header=1。 用 header=0 读出来列名会变成 0,1,2… 外加一列 Unnamed: 0。

结论与下一步

数据质量发现（本日最有价值的一条）

EDUCATION 存在 3 个文档未声明的类别值 0 / 5 / 6。 其中 education = 0 仅 14 条样本、坏率 0.0000—— 这是"方差炸弹"：树模型会为它生成一条精准切割 14 人的规则。
处理（0/5/6 并入 others）后：IV 0.015987 → 0.015683（未提升）， 但最小类别占比 0.047% → 1.56%（33 倍），分箱也由 2 箱恢复到 3 箱。
分寸感：处理数据质量有时是为了"把不稳定的东西变稳定"，不是为了刷指标。

给 Day3 的五条可执行动作

  1. 直接入模 pay_0 / pay_2 / pay_3 / pay_4 / pay_6 / limit_bal（IV ≥ 0.1）。
  2. pay_0（IV 0.87）先做 out-of-time 验证，确认不是泄漏再决定用不用。
  3. EDUCATION 按"0/5/6 合并为 others"编码，不要当作有序数值。
  4. 补充领域特征：信用利用率、逾期次数、还款/账单比（函数已就绪）。
  5. 评估指标选 AUC + KS + 召回率，不看 accuracy；并用 DeLong 或 bootstrap 给 AUC 置信区间。
